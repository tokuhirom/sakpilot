# IAM

さくらのクラウドのIAM(ユーザー・グループ・ロール管理)を参照できます。現状は読み取り専用で、ユーザー・グループ・IAMロール・IDロールの一覧をタブで切り替えて閲覧できます。

## 一覧画面

サイドバーの「グローバルリソース」内「IAM」から一覧に入ります。IAMは組織横断的な機能のため、他のリソースのようなゾーン/グローバルの区分ではなく単一の画面で完結します。上部のタブでユーザー・グループ・IAMロール・IDロールを切り替えます。

### ユーザー

ID・名前・ユーザーコード・メールアドレス・ステータス・説明・作成日が確認できます。

![ユーザー一覧](images/iam/01-users.png)

### グループ

ID・名前・説明・作成日が確認できます。

![グループ一覧](images/iam/02-groups.png)

### IAMロール

さくらのクラウドが提供するIAMロール定義の一覧です(オーナー・編集者・閲覧者など)。ID・名前・カテゴリ・付与可能な最低階層・説明が確認できます。ロール定義自体は固定のため作成・編集はできません。

![IAMロール一覧](images/iam/03-iam-roles.png)

### IDロール

IAMロール導入以前からの旧ロール体系(管理者・メンバーなど)の一覧です。ID・名前・説明が確認できます。

![IDロール一覧](images/iam/04-id-roles.png)

## 今後の対応予定

サービスプリンシパルのキー管理(発行・有効化/無効化・削除)やユーザー・グループの作成・編集など、書き込み系の機能は今後のアップデートで対応予定です。
